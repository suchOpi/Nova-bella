# Nova Bella

Propuesta para Nova Bella, basada en la entrevista con la propietaria. Prioridad acordada: **primero el sistema de inventario, después la web de ventas**.

| Carpeta | Qué es | Cómo verlo |
|---|---|---|
| `inventario/` | Boceto navegable del sistema de inventario y punto de venta | Abrir `inventario/index.html` en el navegador |
| `web/` | Propuesta de web de ventas (rosado) | Abrir `web/index.html` |
| `docs/ficha-tecnica.md` | Requisitos, alcance, fases y preguntas abiertas | — |

Son prototipos sin servidor: los datos del inventario viven en el navegador (localStorage) y son de ejemplo. Los nombres de líneas, modelos y precios son ficticios.
